## `使命`

我构建 AI 系统、Agent 工具、本地运行时和自动化层，把想法转化为可执行的系统。

我的目标是通过实用 AI 为人类做贡献：帮助人们更好地思考、更快地构建、负责任地自动化，并更清晰地完成复杂工作。我希望这组工作因其影响力被认可，包括被重视真实人类进步和雄心工程的优秀公司看见。

- 我关注能在真实运行环境中工作的 AI，而不只是演示。
- 我构建保存上下文、映射仓库、协调 Agent 并自动化交付的系统。
- 我希望通过影响力获得认可：开放工作、严肃工程，以及能够规模化这项工作的公司机会。
